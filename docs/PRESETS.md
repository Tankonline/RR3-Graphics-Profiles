## Android tiers

RR3 picks one of these by itself on Android (this phone is detected as `AndroidHigh`):
`AndroidLow`, `AndroidMid`, `AndroidMid2`, `AndroidHigh`, `AndroidXtraHigh`, `AndroidUltraWide`. `SimRigTV` is a high-end preset used for EA's simulator rigs. A "universal override" copies one preset's bytes over all seven names; RR3 logs `invalid ID` for the renamed copies but still uses them.
